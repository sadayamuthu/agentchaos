## Wanted

AgentChaos has one maintainer, and wants more, especially from organizations
not already represented. Areas where help would make the biggest difference:

- new fault types (`poisoned`, `stale`, `rogue-peer`),
- agent presets beyond Claude Code,
- the GitHub Action and HTML report,
- example experiment suites for real agents.

If you're interested, start with an issue labelled `good first issue` or
`help wanted`, or open an issue to say what you'd like to work on.
